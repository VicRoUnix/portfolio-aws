# Portfolio Web Automatizado en AWS (WIP)

Este proyecto está **en desarrollo**.

## Objetivo
El objetivo es desplegar un sitio web estático (portfolio personal) en un bucket de **AWS S3**, configurado para servir contenido web.

La infraestructura será definida y gestionada como código (IaC) utilizando **Terraform**.

El despliegue será totalmente automatizado a través de un pipeline de CI/CD con **GitHub Actions** que se disparará con cada `push` a la rama `main`.

## Tecnologías
- AWS (S3, IAM)
- Terraform
- GitHub Actions
